# homebrew-onefolder

Homebrew tap for [OneFolder](https://github.com/boraoku/onefolder), a terminal app for macOS that syncs local folders to OneDrive and external drives with rclone.

```sh
brew install boraoku/onefolder/onefolder
```

The formula in `Formula/onefolder.rb` is generated by cargo-dist from each release of OneFolder.
